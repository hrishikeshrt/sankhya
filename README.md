# Saṅkhyāpaddhatiḥ: An Interface for Indian Numeral Systems

Source code associated with https://sanskrit.iitk.ac.in/jnanasangraha/sankhya/.

There are three numeral systems supported:

1. Kaṭapayādi Saṅkhyā
2. Āryabhaṭīya Saṅkhyā
3. Bhūtasaṅkhyā

# Cite
